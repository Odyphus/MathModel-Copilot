# MCM/ICM evidence gap

`empirical.json` deliberately records `papers_total = 0` and contains no numeric distribution. Earlier seed values for words, figures, formulas, references, or letters were maintainer estimates, not measured samples or official COMAP thresholds, and have been removed.

## What is authoritative

- current submission constraints: the official link in `current_rules.md`;
- problem-specific deliverables: the current contest problem;
- team results: reproducible code, data, and saved artifacts.

`winning_patterns.md`, `anti_patterns.md`, and `paper_skeleton.md` remain maintainer-authored review aids. They cannot support award predictions or numeric paper-shape targets.

## Before adding empirical data

Document provenance and permitted use, record year/problem/award labels separately, report extraction failures, retain per-group sample sizes, and review outliers before committing aggregate statistics. Update `empirical.json` only after the process can be reproduced and audited.
