## 与另外两条分支的关键差异

- 官方版式明确：封面第 1 页，摘要第 2 页并从 1 编页码，正文第 3 页开始，不要目录。
- 当前官网规范要求正文控制在 25 页以内，附录置于正文之后且页数不限。
- 正文与支撑材料分开提交；支撑 RAR/ZIP 不超过 20MB，并应包含可运行代码和必要证据。
- 工程语义是内部复核重点：单位、物理边界、实施条件和失效情景必须可追溯，但仓库不假定固定图数、段数或建议数。
- 当前核对页面没有专门 AI 披露格式；这只是“未在这些页面发现”，仍须检查当年通知并保留台账。
