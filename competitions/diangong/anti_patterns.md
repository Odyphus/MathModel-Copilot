# 电工杯反模式 (SEED v0.2)

> 12 个电工杯启发式检查项。stage 9 终审逐条对照；它们不是官方评分权重（CUMCM 包为 42 条）。

---

## A. 工程实用性类

### A1. 数值最优但工程不可行
**症状**: 模型给出"最优配置 = 储能 200MWh", 但该规模在题目背景市/省一年内不可能建成。
**修复**: 加"工程可行性约束"段, 说明实际可达规模, 给出 2-3 阶段实施方案。

### A2. 没有工程参数语义
**症状**: 结果只用"x = 0.345", 不说"对应渗透率 34.5%"。
**修复**: 数值结果旁带物理 / 工程语义 + 单位。

### A3. 结论无实操建议
**症状**: 结论段只重复方法和结果, 不给电网公司 / 能源企业可操作建议。
**修复**: 给出证据支持的动作、对象、代价、时序和重新评估条件；数量由结果决定。

---

## B. 数据使用类

### B1. 题目数据未用全
**症状**: 题目附带 5 个 Excel sheet, 论文只用了 3 个; 漏掉的字段评委会注意到。
**修复**: 列出全部 sheet/列及用途；未使用字段说明无关、冗余或质量不足的理由。

### B2. 数据预处理省略
**症状**: 直接从"题目给出数据 → 模型求解", 跳过缺失 / 异常 / 单位统一。
**修复**: 单独 1-2 页"数据预处理", 含统计描述 / 缺失处理 / 异常剔除规则。

### B3. 数据来源 / 采样信息缺失
**症状**: "我们使用了某省负荷数据", 不说时间跨度 / 采样频率 / 行数 / 字段。
**修复**: 数据章节首段强制 "{N} 条记录, {时间跨度}, 采样 {频率}, 字段 {list}"。

---

## C. 子问题处理类

### C1. 6-8 子问数全部平摊处理
**症状**: 每子问 3 页, 全部平铺, 主问题反而没说透。
**修复**: 按下游依赖、结论重要性和失败风险分配篇幅，不设固定每问页数。

### C2. 子问之间无复用
**症状**: Qi 各自独立, 不调用前面的解。
**修复**: Q3 显式 "基于 Q1 求得的负荷预测, ..." 形成复用链。

---

## D. 灵敏度类

### D1. 灵敏度参数无工程意义
**症状**: 扰动"参数 a = 0.3 → 0.27"。评委不知道这是什么。
**修复**: 用工程参数 (光伏渗透率 / 储能配比 / 负荷增速 / 故障率), ±20-50% 扰动。

### D2. 单参数 OAT 而非联合
**症状**: 只做 one-at-a-time。
**修复**: 参数交互会影响结论时使用联合设计；否则说明 OAT 足够的依据。

---

## E. 写作类

### E1. 通用 matplotlib 配图风
**症状**: 图都是 default matplotlib, 不像电力专业。
**修复**: 选择能解释拓扑、时序、潮流或风险的图形；统一单位、字号和图例，不为“专业感”滥用图种。

### E2. 章节结构散乱
**症状**: 子问之间章节标题层级混乱。
**修复**: 每子问统一 3 级结构 (问题分析 / 模型建立 / 求解结果 / 灵敏度)。

## 评估协议 (stage 9)

| 反模式 | 检测方式 | 命中后行为 |
|--------|---------|-----------|
| A1 | 推荐方案规模 vs 题目背景物理上限对照 | warn |
| A2 | 数值结果段是否含 kW/kWh/%/单位 | refine |
| A3 | 每条建议能否回指实施主体、动作、证据、代价/约束与重估条件 | refine |
| B1 | 所有附件 sheet/关键字段是否都有“使用或有据不使用”的记录 | refine |
| B2 | 预处理规则、受影响记录数及其对结果的影响能否追溯 | refine |
| B3 | 外部数据能否追溯到时间跨度、采样频率、记录数与字段来源 | refine |
| C1 | 篇幅与求解预算是否匹配子问依赖、结论重要性和失败风险 | warn |
| C2 | 下游子问是否引用上游结果，或明确说明为何相互独立 | warn |
| D1 | 灵敏度参数表是否含工程量纲 | warn |
| D2 | 验证方法是否匹配参数交互风险；使用 OAT 时是否给出充分依据 | refine |
| E1 | 图形是否真正解释拓扑、时序、潮流或风险，并统一单位与图例 | warn |
| E2 | 标题层级是否与题面子问和依赖关系一致 | refine |
