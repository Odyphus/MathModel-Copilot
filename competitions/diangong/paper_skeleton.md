# 电工杯论文骨架

> 当前官网基线：A4 四边 2.5cm、宋体小四；第 1 页封面，第 2 页题目/摘要/关键词并从 1 编页码，第 3 页正文；不要目录；正文 25 页以内，之后附录页数不限。每届仍须复核 `current_rules.md`。

## 工作区文件

| 文件 | 内容 |
|---|---|
| `01_abstract.md` | 第 2 页摘要正文与关键词，无顶层标题 |
| `02_problem_restate.md` | 问题背景、任务与数据范围 |
| `03_analysis.md` | 子问题、依赖与技术路线 |
| `04_assumptions.md` | 假设、依据与影响范围 |
| `05_notation.md` | 符号、索引与工程单位 |
| `06_models.md` | 建模、求解、结果、解释与实施建议 |
| `07_sensitivity.md` | 验证、稳健范围与失效条件 |
| `08_evaluation.md` | 优点、局限、改进、推广与结论 |
| `09_references.md` | 按正文顺序列出的已核验来源 |
| `10_appendix.md` | 附录内容与支撑材料清单 |

文件 `02`–`10` 各自保留一个顶层 Markdown 标题；模板提供封面与摘要标题。

## 建议证据链

```text
[第 1 页：报名序号 + 赛题论文题目]
[第 2 页：论文题目 + 摘要 + 关键词，页码 1]

1. 问题背景与任务
2. 问题分析与技术路线
3. 假设、符号与数据处理
4. 各子问题：公式 → 求解 → 结果 → 验证 → 工程解释
5. 稳健性与失效条件
6. 模型评价、实施建议与结论
7. 参考文献

[正文之后：附录]
```

章节名称和数量可随题目调整；不要为保留骨架而生成空节。正文篇幅优先给关键依赖、核心结论和高风险验证，附录用于必要代码与大篇幅中间结果，但支撑材料仍需单独打包。
