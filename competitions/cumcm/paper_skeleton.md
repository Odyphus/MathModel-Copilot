# CUMCM 论文骨架（Markdown 中间产物）

> 本文件给出内容占位符，不替代当年格式要求。开始写作前先检查同目录 `current_rules.md`；详细工作流见 `../../references/stage_08_writing.md`。

## 提交边界

当前规则基线要求电子论文第一页为摘要页、不放目录、不包含承诺书或编号页、不暴露身份，正文不超过 30 页。页数、文件大小、附录和 AI 使用材料以当年官方通知为准。

59 份可提取样本的观察值见同目录 `empirical.json` 与 `empirical_notes.md`。来源清单共 91 份；不要把样本分位数当成官方阈值。

## 工作区文件

`render_paper.py` 按下列文件名装配论文：

拆分到工作区时，`01_abstract.md` 只写摘要正文与关键词，不保留 `# 摘要`；`02`–`10` 各保留一个顶层标题。下面的连续骨架用于展示最终结构。

| 文件 | 内容 |
|---|---|
| `01_abstract.md` | 摘要与关键词 |
| `02_problem_restate.md` | 问题重述 |
| `03_analysis.md` | 问题分析与技术路线 |
| `04_assumptions.md` | 假设及依据 |
| `05_notation.md` | 符号、单位与索引 |
| `06_models.md` | 各子问题建模、求解与结果 |
| `07_sensitivity.md` | 验证、敏感性与稳健性 |
