# Visual assets

The illustrations used in this README were supplied by the project maintainer for this visual edition. They are conceptual illustrations, not screenshots of the product. The original artwork is preserved locally; the public WebP files are typeset derivatives for README display.

Headings are typeset with Fusion Pixel Font (10 px proportional Simplified Chinese, release 2026.09.25): https://github.com/TakWolf/fusion-pixel-font. Its OFL and upstream notices are retained in font-licenses/. Body text is rendered using the local Windows Microsoft YaHei font; font software is not distributed.

The original README wording, emphasis, and link targets are retained in the expandable text section. Each section has a separate mobile image selected by the picture element.
