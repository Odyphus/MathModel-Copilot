# 写作辅助、图表取舍与摘要材料

按需使用：进入每问结果解释、图表建议、论文或摘要辅助时读取。本协议不替代 Runtime、Claim、PaperSection、装配与最终交付检查。

## 1. 先交付作者可以使用的材料

默认以 `templates/copilot/writing_materials.md` 为参考，按当前任务裁剪，不要求用户填写模板。每问先交代：

- 题目实际要求、准确模型名称、数学结构、求解算法和适用假设。
- 当前已采用的选择；候选/已运行/已核验分别说明，不把建议写成团队决定。
- 从本问、本工况、当前版本结果读出的关键数值，附结果文件及证据定位。
- 可以支持什么判断、哪些判断仍缺对照或误差证据。多项条件同时变化时不能单独归因于其中一项。
- 可用图表与待补论证，人工需要判断的具体问题。

作者已有草稿时，默认给“原段落定位—问题—证据—建议”的批注。用户需要局部改写时另存候选，显示改了什么；不要自动覆盖作者正文。摘要、排版或检查需求不意味着授权自动重写全文。用户已明确授权的工作持续完成，不增加每段审批。

## 2. 主动判断该不该画图

先确认要让读者看懂或相信哪一个结论，然后比较图、表和一句数值陈述。建议附以下信息，能简短说清就不展开表格：

| 要素 | 判断依据 |
|---|---|
| 建议 | 推荐、暂不推荐，或数据齐备后再做；不规定每问图的数量 |
| 论证用途 | 解释机制、呈现主结果、对比方案、验证误差或展示适用边界中的具体用途 |
| 模型/结果适配 | 为什么这种图适合当前变量、时间/空间结构和比较任务 |
| 来源与映射 | 小问、运行、ParameterSet 版本、输入文件、横纵轴字段与单位；不能混入索引/时间列 |
| 信息增益与成本 | 相比现有图表新增什么、会不会重复、是否需要额外实验及核验；未测时间只给粗估并注明 |
| 解释边界 | 坐标截断、汇总方式、样本量、不确定性、因果或最优性不能由图单独证明的部分 |

“高级”只落实为更准确的信息表达：例如同尺度对照、误差带、残差诊断或可行域，不以复杂、3D、渐变装饰为质量标准。以下是候选而非默认任务：

- 传热/扩散模型：固定若干真实时刻的径向剖面适合比较梯度；时空热图适合看全局演化。两图回答相同问题时保留信息更清楚的一张。网格收敛图属于数值验证，与真实实验吻合度分开说明。
- 优化模型：约束一致时对比目标值与关键资源占用；Pareto 前沿只用于实际得到的多目标解，不能虚构采样点或以启发式结果声称全局最优。
- 预测模型：按真实训练/测试划分展示误差、残差或校准；不因拟合曲线平滑就判断预测有效。只有定义和计算成立时才画置信/预测区间。

定量图必须由实际数据和绘图程序生成，不用生成式图片绘制数值证据。概念图可单独辅助讲解，明确它不代表计算结果。生成后回看实际图片的字段、数量级、轴/单位/图例、颜色可辨性和字体；材料预检不代替看图。

## 3. 摘要先选事实，再组织语言

先在材料卡中回答：解决了什么问题；实际使用什么模型/算法；每问哪些已核验结果最有代表性；验证和适用边界是什么。结果不全时提供带明确缺口的提纲，不制造完整成功故事。作者需要候选摘要时再组织文字，摘要中的数值和专业名称回到正文及当前来源核对，不能夸大因果、鲁棒性或最优性。

优秀论文样例只提炼可观察结构和论证选择，不先断言“近年高奖论文都遵循某种模式”。使用 `templates/copilot/abstract_case.md` 记录样本来源、赛事/年份、可核验奖项、访问日期、使用/再分发范围、原文位置、观察和反例；没有授权不能再分发全文。公开可读不等于可收入发行包。

先从用户有权提供的小样本开始，比较“问题—方法—结果—验证/边界”如何取舍，报告实际样本量和选择偏差。不同赛题、赛事和摘要篇幅分开分析；奖项不证明某种措辞有效。输出可复用的评审问题，不能把案例的数字、模型、结论或句式整段套进当前论文。本版提供接入模板，未交付已核验的优秀摘要案例库。

## 4. 运行机械检查，再做内容与页面检查

当前已登记的论文表格或绘图 CSV，可用 `templates/copilot/paper_review_contract.json` 为起点，由 Agent 从权威记录填真实对象和相对路径，并按题意填列、单位和依据。原表若来自 Excel，保留原件，导出实际用于论文/图的 CSV 并登记依赖已核验 Result 的 ArtifactRecord。无需要求用户手改对象编号。

```bash
python <skill>/scripts/copilot_paper_review.py --workspace <project> --contract paper_materials/review.json
```

检查读取当前权威状态并复用既有对象/文件来源检查：实际来源小问、运行使用的参数版本、派生表依赖、缺列、重复表头、破损行、非有限值和声明范围。温度列混入时间值可由有依据的范围暴露。表中收缩后失效的位置可使用有解释的缺失标记，不能直接显示 `nan`，也不能偷偷改成 0。

材料中通过的范围仅表示符合声明标准；标准本身和数据是否被正确生成仍需独立核验。正文 Markdown/TXT 可筛查程序缺失值，但不能靠这个检查证明语义、小问文字、因果关系或作者确认正确。没有声明的表/图也不在本次覆盖范围内。

检查输出 `passed` 只表示该批材料机械预检，不写权威状态、不改变 PaperSection 的 verified、不产生 Ready。继续使用既有 Claim/Section 与 DOCX 来源回读协议；最终 PDF 必须另查实际页数、图像裁切、缺字和图注。发现错误先修正对应来源或生成代码并重跑，不通过润色隐藏问题。无排版引擎时保留结构预览并说明“最终排版未验证”。
