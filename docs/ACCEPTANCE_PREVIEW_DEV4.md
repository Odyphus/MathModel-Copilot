# 0.3 Preview 开发增量公开更新（2026-10-10）

本次将已完成本地验证的 `0.3.0-preview.3.dev4` 推送至公开仓库，并同步固定 latest 下载入口。沿用开发版本号，保留 Preview 属性、schema 4.0、README 原文及宣传素材。未改用户现有安装或比赛项目。

## 本轮累计改进

- 明确 CSV/XLSX 的列、单位与时标，保留原位置、归一化结果及写后读回检查。
- 增加可选 LP/MILP、回归和简单基线；滚动预测按实际可用信息回测，保留逐实例结果及来源；方案比较明确前提，不自动宣称最优。
- 从当前核验章节生成原生 Word，并读回内容；PDF 转换依赖本机工具，导出状态不能替代论文定稿。
- 教学目录覆盖新增功能；常用入口提供字段帮助；运行输入可从当前记录整理，缺失、歧义或失效时给出具体原因。
- 建模工作台改善长文字、来源变更、失效原因和指标说明展示，仍从现有权威记录读取。
- 使用反馈支持结构化复现过程、本地预览与导出；保留来源、脱敏、内容确认及发送授权，未执行真实 Issue 发送。
