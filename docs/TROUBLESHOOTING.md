# 常见问题

| 现象 | 检查与处理 |
|---|---|
| 找不到 `mathmodel-copilot` | 使用安装环境内的完整命令路径，或该解释器的 `-m mathmodel_copilot`；不要换到另一个 Python |
| 同一 Skill 出现多个入口 | 使用 `runtime-review` 用户运行包或默认安装器；不要让宿主递归扫描完整源码、同时注册插件和运行安装，或默认启用旧名。安装器拒绝覆盖，保留原安装并在新目录验证后切换宿主注册 |
| 文件同步（fsync）失败 | 本次权威文件替换会停止，原状态保留。检查磁盘空间、权限和存储状态；不支持同步的目录请把完整项目复制到本地可写目录，再用 `python scripts/copilot.py --workspace 项目目录 host` 检查。不要静默忽略同步错误；探针会保留错误编号及实际失败步骤 |
| 原生 ZIP 导入提示文件数量或类型不支持 | 记录宿主名称、版本、导入入口、原始错误和所用包。优先尝试用户运行包；仍不支持时使用宿主可用的本地文件安装路径。不删除许可证、模型模板或运行引用来凑未知限制 |
| 解压中文文件名失败 | 当前工具创建的中文条目使用 UTF-8 标记。先检查 ZIP 完整性、解压器版本和目标目录权限/文件系统；换可写目录或支持 UTF-8 的解压器复核。单凭 Input/output error 不能确定编码故障 |
| 资源缺失 | 执行 `--resource-root`；正确 wheel 内应同时包含 scripts、competitions、templates、references、dashboard；不要只复制 Python 模块 |
| 新项目目录已有内容，demo 拒绝 | 换一个空目录；演示不覆盖已有工作 |
| 第二次 init 没重置状态 | 这是 create-only 保护；继续 status/context，确需另起项目时选择新目录 |
| revision 冲突 | 重新读状态/Context，核对已接纳变化后重建提案；不要手改权威 JSON |
| status 显示 stale 或缺证据 | 阅读具体来源/运行/检查绑定并重新运行或核验受影响环节，不能只改状态标签 |
| 找不到 `docx`、`pypdf`、`yaml` 或 XLS 模块 | 在同一个环境安装相应 optional extra；核心标准库安装不包含这些功能 |
| CUMCM 官方附件缺失 | 按 [HISTORICAL_FIXTURES.md](HISTORICAL_FIXTURES.md) 独立取得；清洁包刻意不分发 |
| Windows 临时目录无写权限 | 将 TEMP/TMP 指向本次工作目录下已有的可写临时目录，再运行测试；勿指向系统目录 |
| pip 缓存无权限或构建重试失败 | 初次体验可直接使用源码入口；确需安装时使用 `--no-cache-dir`。选择较短的可写临时目录；上次构建目录有残留时从原ZIP解压到新目录重试，保留旧项目和证据，不清空它们 |
| Windows 从 sdist 构建时长路径报找不到文件 | 将源码或 `verify_install.py --work-dir` 放到较短的可写目录；深层构建临时目录可能超过宿主路径限制，不需要修改系统配置 |
| Dashboard 端口被占用 | 选择另一个本机端口，如 `--port 8766`，使用终端报告的地址 |
| Dashboard 读取失败或文件变了 | 查看明确错误/失效状态并重新观察；不能把上一次快照当作当前有效 |
| Windows 更新状态时暂时无法读取 | 对原子替换期间的短暂文件占用，系统最多重试 0.75 秒；持续权限错误仍会报错。检查项目目录权限或长期占用文件的程序，不手改权威状态或回退到旧快照 |
| 没有 Git/不是仓库 | 默认 Local 模式可用；不必为了演示创建远程仓库 |
| DOCX `unsupported` | 按 [DOCX_INLINE_V013.md](DOCX_INLINE_V013.md) 的边界替换/明确处理构造；不删除来源检查绕过 |

报告问题时给候选版本、操作、预期/实际结果和最小合成复现。不要附密钥、私人绝对路径或受限赛题。日志在本地保留，公开前另做脱敏副本。

结果交付应先给少量关键结果、单位与对应实际文件，使用当前宿主确实支持的附件/下载入口。云端临时路径不代表用户能下载；没有下载能力时应明确说明并提供小表格或保存方法，不伪造链接，不把上万行结果直接塞进聊天，也不自动上传私人文件。
