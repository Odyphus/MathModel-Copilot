# 建模意见与 AI 分析

建模工作台默认用于看当前进展。“建模意见”用于讨论当前题目；向产品开发者报告问题的“使用反馈”是另一个仍在设计的通道。见 [产品术语与文案规范](PRODUCT_LANGUAGE.md)。RC4 引入的意见入口在 Preview 中保留，可显式打开，也可进一步连接本机 Codex CLI。它复用现有界面、任务交接说明和统一项目记录，不需要部署新的云服务；不接管用户已经打开的桌面聊天。

## 选择需要的模式

下面从解压后的产品目录运行。`PROJECT` 替换为已有比赛/练习工作区，项目继续使用原来的 `state/decision_log.json`。安装和首次创建项目见 [INSTALL.md](INSTALL.md)。

```console
python scripts/copilot.py --workspace PROJECT dashboard --port 8765
```

这是默认只读模式，查看进展不会启动模型。

```console
python scripts/copilot.py --workspace PROJECT dashboard --port 8765 --interactive
```

这是本地建模意见模式：可持久保存意见或问题，关联任务/小问，并在允许的状态下撤回。未配置执行器时不调用 AI，也不能把“已记录”显示成“AI 已处理”。意见存在原 Store 中，刷新页面或重启服务后可继续查看。

```console
python scripts/copilot.py --workspace PROJECT dashboard --port 8765 --interactive --assistant-codex --assistant-timeout 180
```

这是可选 AI 模式。调用者需要已有可运行的 Codex CLI 及其登录/使用条件；启动参数允许的超时范围为 10–900 秒。页面只向服务器提交结构化问题，执行命令与工作区由服务器持有，不开放任意 shell 命令入口。浏览器访问启动时给出的本机地址，终端中 Ctrl+C 结束服务。

三个示例均使用主入口 `copilot.py`。安装 Python 分发包后可将 `python scripts/copilot.py` 换为对应环境的 `mathmodel-copilot`；不要把启动开关添加到不支持它们的其他脚本入口。

## 一次分析会发生什么

1. 用户输入意见，可以先保存，或明确请求 AI 分析。
2. 系统检查当前项目和页面版本，保存请求；旧页面遇到冲突时刷新后再提交，不覆盖新状态。
3. 明确的分析请求由本地执行器读取当前任务交接说明，启动一次新的只读 CLI 分析。只选小问时不会误用另一小问的当前任务；明确指定任务时核对它与小问的对应关系。分析工具、连接器和插件被关闭，只分析所提供的材料；它不向原桌面会话发送消息，也不恢复那个会话的隐藏历史。
4. 页面分别显示等待、执行、完成或失败。只有取得有效的完成回执和回复，才显示本次分析完成；收到 HTTP 响应或进程退出码 0 本身不够。
5. 答复可以帮助队员判断下一步。模型修改、采纳、真实求解、数学验证和交付仍走原专用流程，不由一条 AI 回复自动完成。

项目依据已变化时，旧回复只能作为历史参考，不能继续标成适用于当前版本。用户撤回、执行超时、服务停止和启动失败也应各自如实显示，不能统一为“已完成”。原始意见不可原地改写；修改想法时补充新意见，保留上下文。

## 用量与日常成本

保存意见、撤回、刷新页面和轮询状态均不调用模型。明确请求 AI 分析时，执行器才可能使用本机配置的账户和对应额度；次数、计费及可用性取决于实际环境，产品不承诺免费。

可把同一任务的一组相关问题合并提交，减少反复补上下文。相同请求的精确重试复用已有回执，不重复登记；服务重启不会自动重放未完成分析。若用户重新发起分析，那是新请求，不应理解为取消会返还此前已产生的用量。

## 状态和协作边界

- 页面请求、回复和历史都复用原 Store；没有第二个可覆盖权威事实的页面数据库。
- “意见已保存”“AI 已回复”“队员已采用”“结果检查通过”是不同事实。AI 回复不自动生成成员采用/核验回执。
- 页面仅监听本机；写入需本机来源和当前写入会话。服务器所有者配置执行器，页面没有直接执行任意脚本或更换工作区的接口。
- 此版并非三人实时云协同。Git 搬运和接纳流程仍按 [GIT_COLLABORATION.md](GIT_COLLABORATION.md) 执行，Git 合并不得绕过状态检查。
- 不可用时继续保存意见，或由用户复制续接说明到可用的 AI 宿主。保存成功不等于已经唤醒那个宿主。

## 当前验收状态

2026-10-06 的 Preview 真实试跑发出一次合成项目的只读请求，页面接口接受后依次记录等待、执行、失败；177.5 秒后返回宿主目录或进程权限受限提示，未取得 AI 回复。原意见保留，业务对象没有改变。此提示是执行器的错误分类，不构成对外部宿主故障根因的完整诊断。

**“页面请求 → 真实 AI 完成 → 页面收到回复”本轮没有通过验收**；该能力仍为默认关闭的实验选项。合成执行器、协议与取消测试只覆盖相应软件行为，不代表任意账户或宿主已经接通。候选版随附真实接入结果，保留失败和未验证范围，不以配置成功推断接通。

没有启用执行器、找不到 CLI、权限不足、登录/额度不可用或任务失败时，应使用页面实际回执判断；不要仅凭检测到命令就认为连接可用。这个未验收边界不影响默认只读页面和本地意见记录的独立使用。
