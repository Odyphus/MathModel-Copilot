## 本轮实际修复

- 凭据脱敏完整覆盖 Authorization Bearer/Basic、带引号及多行输入。
- 同一体验换反馈草稿、重配分享选项仍不能重复发送；未知发送先核对。
- 限定自动分享只重建程序允许字段，不发送题目目标、自由文本或片段。
- 本地复盘实际落盘并回读，不覆盖人工修改；保存与删除并发时不复活记录。
- 非 Windows 平台先创建仅本人访问的个人目录，再创建锁；宽权限写入拒绝。
- 补齐当前版本的入口标题和 SVG 文案；最终运行包重建后重新安装验证。
