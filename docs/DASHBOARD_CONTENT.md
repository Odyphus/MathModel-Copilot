# 建模工作台：内容与状态规则

功能名称、状态含义及对外表达以 [产品术语与文案规范](PRODUCT_LANGUAGE.md) 为准；本文件说明具体展示行为。

## 用途与范围

工作台帮助使用者看懂本机项目的进展、已有成果、问题和下一步。页面不假设已经收到所有队友的最新工作。现有 Git 协作能力保留；没有新增远端同步或云端账号。默认服务保持只读；显式启用交互模式后，可通过受控接口保存意见，并在有可用本地执行入口时请求只读 AI 分析。

页面是随包固定资产，不随题目重新制作。开发版 Skill 的 [首次与按需功能引导](../references/feature_guidance.md) 要求：完整项目就绪且宿主支持时主动启动并尝试展示只读工作台；局部问答、用户拒绝或环境不可用时保留对话体验。CLI 的 `init`/`demo` 不自动开浏览器，工作台服务不自动抢焦点或重开标签；实际打开、排队和仅提供地址要按工具结果区分。默认介绍和有条件展示不把工作台变成使用其他功能的前置要求。

## 内容结构

| 位置 | 内容 | 来源及显示条件 |
|---|---|---|
| 页头 | 项目、题目、练习/正式比赛模式、读取时间 | 来自本次权威观察；只有记录了有效截止时间才展示截止时间 |
| 首页各问进展 | 题目目标、当前方案、已核对要求、当前工作 | 按全部要求行及当前对象发现小问；相同描述可摘要，数量不合并 |
| 首页变化摘要 | 自本浏览器上次已读标记之后的新增、变化和失效事项 | 来自当前观察的差异；“已看过”只更新浏览器阅读标记，不改变项目状态 |
| 首页下一步 | 当前工作及明确需要人工确认的事项 | 优先使用内核的题意歧义、假设投影；保留其他人工提交检查，已通过的材料审计不再作为同一重复操作推荐 |
| 首页需要你判断 | 题意候选解释、假设内容、已登记影响及依据 | 只读 `status.interpretations` 的当前记录；条件推进不等于歧义已解决，采纳不等于数学核验 |
| 首页主要成果 | 当前计算结果及检查状态 | 当前 ResultRecord；核验不等于适用范围之外的效果成立 |
| 首页待解决问题 | 已记录阻碍与当前记录的失败/失效 | 只在有实际记录时出现；历史被替代版本不自动成为当前阻碍 |
| 首页论文准备 | 已登记章节、文件、实际提交边界 | 有相关记录才出现；章节来源检查不代替整篇论文检查 |
| 变化影响 | 当前需重检的记录及对使用的影响 | 存在当前失效内容时出现；不能把历史版本保留说成项目失败 |
| 各问进展 | 完整要求、任务、方案、参数、数据与结果 | 逐层展开；不遗漏子问或要求 |
| 成果与依据 | 结论、结果、图表；可切换计算过程、模型资料和全部记录 | 当前记录默认；可按需查看旧版本 |
| 论文准备 | 章节、相关文件、材料检查和实际提交情况 | 所有提交阻碍必须可见，包含历史/研究与人工检查边界 |
| 页尾辅助入口 | 本机变化、诊断导出 | 普通页面不展示内部编号；诊断文件保留精确原始记录 |
| 建模意见与 AI 回复 | 项目整体或已登记小问的意见、处理状态、分析回复 | 独立交互接口读取，写入只在显式启用后提供；不改变原只读快照契约 |
| 数字来源与检查依据 | 指标含义、声明单位、适用范围、数字对应关系、运行/检查/结果文件 | 在结果或结论详情按需展开；现场派生，不信任旧缓存绑定 |
| 项目决策 | 既有决策文字、理由、时间及可选登记署名 | 总览提供入口，在本机变化内只读展示；文字记录不自动采用模型，署名不证明人工身份 |

没有真实内容的成果、人工待确认、问题或论文概况不占首页。首次使用的题目区仍解释如何开始，不能用空页面暗示一切完成。

## 中文及来源

- 控件、导航、系统状态和已知阻碍使用中文。
- 计算记录以“第 2 问的计算记录”等名称显示，不回退到内部编号。
- 科学方法、单位、实际数值和合法原文件扩展名不因包含英文而被删除。
- 已知来源句可做确定性中文映射；未知英文不自动编造结论或理由。必要原因通过“查看具体原因（原文）”保留。
- 模型的选择理由、假设及约束仅展示已有记录，不从运行成功推断模型正确或全局最优。
- 指标名称、单位与适用范围来自实际上游 `ModelSpec.outputs` 的明确声明：`name` 精确匹配一级指标名，或显式 `metric_path` 匹配 JSON Pointer；`meaning`（或 `label`）、`unit`、`scope` 按原声明读取。不再把 `capacity` 固定解释为交通通行能力，也不把 `horizon` 固定解释为秒。缺失即显示未登记，多份冲突声明不擅自选择。元数据声明不等于单位科学核验。
- 数值展示不建立第二套状态。`metric_details` 是同次观察的只读派生，最多列出 128 个数值指标；详情默认依原顺序显示前 20 项，并明确告知截取范围。完整 `metrics` 原文仍可展开，不只展示有利结果。
- Claim 的 `numeric_provenance` 每次调用既有 `claim_assurance` 重算，并与实际 Result、运行和检查关联。数字匹配与显示舍入不证明自然语言推论、因果关系、适用范围或数学最优；同值多来源明确提示歧义，旧式点路径无法唯一定位时不猜测指标。未知来源与同 revision 文件变化不能继续显示为当前有效。
- ValidationReport 按原回执展示检查结果、运行前 `criterion`、可选实际观测值及证据入口；页面不解析文字阈值或自行计算通过状态。未登记或未知来源保持明确缺失。
- 完整计算数据和原始文本文件可以明确展开查看；常规摘要不只挑有利结论。
- 文件入口保留注册及版本检查。文本可在工作台读取，其他格式提供复制项目内位置；没有新增任意文件读取或二进制下载接口。

## 状态语义

“已运行，待检查”“已检查”“已完成材料检查”“待提交”“已提交”分别表达各自记录，不可相互替代。题目要求核对完成不表示论文完成或正式可提交。旧版本使用“旧版本”，当前文件变化使用“需要重新检查”。没有记录时保持未记录或未确认，不能生成已收到、已采用、人工批准或队友在线等事实。

本地刷新失败会撤下之前的当前事实。诊断按钮及详情不绕过原权威状态、文件绑定或只读限制。

离开页面后返回、切回应用窗口或从浏览器历史恢复页面时，工作台会重新读取本机状态；这不代表收到远程队友的更新。旧请求不能覆盖后发请求的结果。参数详情按已登记的参数条目显示含义、取值及单位，不根据内部代号猜测参数含义。

## Preview 2：连续阅读与待决策事项

- 固定 HTML/CSS/JavaScript 页面继续复用；新增 `workbench.js` 只负责纯展示数据计算，无网络或业务写入。页面不会随题目或刷新重新由 AI 制作。
- 阅读游标按项目保存在本浏览器、同一地址的 localStorage 中，只有对象 ID、状态和比较标记，不存题目正文或数值。首次可用观察建立基准；后续刷新或重载不自动消除未读变化，只有“这批变化已看过”更新基准。损坏、跨项目、未来版本等游标会舍弃。游标不参与事实核验；即使被修改，也不能改变当前阻塞、Ready 或采用状态。禁用浏览器存储时退化为本页内记录，换浏览器或端口不承诺续接。
- 摘要优先显示失效及成果变化，并保留其他变化入口。对比同时包含当前对象、要求、任务和关联文件观察，不能只看 revision；观察时间自身不产生“有新进展”。当前状态仍从本次服务响应读取。
- 待判断事项来自现有内核投影，不由关键词猜测题意决策。开放歧义、待采纳假设与依据已失效的解释分别展示；`conditional` 明确显示可带条件推进但仍未解决。已接受但尚未检查的假设保留在实际检查阻碍中，不伪装为尚未做出的选择。未登记建议与理由不编造。
- “复制讨论提纲”只复制到剪贴板；失败时显示可手动选择的文字。它不调用 AI、不保存意见、不采纳假设，也不改变题意或模型；用户粘贴到既有 AI 对话后再继续讨论。
- 页面可见时每 15 秒进行一次本机状态观察，隐藏时暂停。刷新不是模型调用。返回事件成对触发时只启动一次观察；较旧的请求不能盖过较新的读取。
- 刷新中保留阅读内容并明确标为上次观察，暂停交互写入和文件读取。成功且没有内容变化时不重建页面；内容变化时保持筛选、展开项与阅读位置，重新解析详情及后退栈中的对象。新版本替代后读取新版本；记录消失则撤下原内容。同 revision 文件漂移仍可使原结果失效。文件原文在观察变化后须重新打开。
- 读取失败撤下旧事实并关闭旧详情。刷新期间导航、详情后退、旧文件回复和跨项目切换均有负向回归，不依赖仅按 revision 缓存的“当前状态”。

验收目标是减少重新理解项目的负担；本轮浏览器验收不等于已经测得“30 秒看懂”或真实用户满意度。

## 建模意见与 AI 分析：首轮可操作范围

- 继续复用四个主要导航、原页面骨架与样式；`interaction.js` 单独维护表单、意见回执和协议请求，不生成另一套题目页面。
- “保存意见”只保存到本机项目，不启动 AI；“请 AI 分析”只在服务确认有可用执行入口后启用。只有显式点击才发起模型任务，定时刷新仅调用本地 HTTP 读取接口。
- “已记录、等待处理、正在分析、正在停止、已回复、未成功、已中断、已撤回、项目已变化，需重新分析”分别显示实际回执；“正在停止”须等执行器确认结束后才显示已撤回。“已回复”不等于方案已采用、计算已执行或结果已核验。首轮不能从页面直接修改参数、采用模型、运行实验或提交论文。
- 每条意见可关联已登记的小问；不向用户显示内部项目号、请求号或版本码。文字和 AI 回复通过纯文本 DOM 呈现，不执行 HTML 或脚本。
- 刷新页面保留按项目隔离的会话草稿。草稿不是权威记录；保存成功后才清空已提交文字，用户在等待时继续输入的新文字不被清除。浏览器禁用存储时仍可在本页使用草稿，但重载不能保证恢复。
- 重复点击不产生第二次并发提交。网络断开造成回执不明时保留完整原请求，用户显式重试复用原请求号、文字及版本。版本冲突不自动重发：保留输入，读取新状态，明确提示用户查看新进展后再提交。
- 无 AI 适配器时仍可记录意见；默认只读模式只提供复制续接说明。复制成功不显示为“AI 已收到”；自动复制被浏览器拒绝时提供可手动选择的完整文字。
- 对未处理的意见提供撤回，分析中提供停止操作。页面只展示服务实际回执，不承诺撤回会回滚其他产物。
- 意见读取失败时收起旧处理状态，暂时禁用写入；原工作台的其他只读内容不因此全部不可用。切换项目时不能应用上一项目的迟到响应。

## 复核入口

```text
node --test tests/test_dashboard_presentation.js tests/test_dashboard_resume.js tests/test_dashboard_interaction.js tests/test_dashboard_numeric.js tests/test_dashboard_workbench.js
python -m unittest discover -s tests -p test_dashboard_v020.py -v
python -m unittest discover -s tests -p test_dashboard_numeric.py -v
node tools/verify_dashboard_ui.js --url http://127.0.0.1:PORT --output NEW_DIRECTORY --channel chrome
node tools/verify_dashboard_continuity.js http://127.0.0.1:PORT NEW_DIRECTORY
```

浏览器验收需要可选 Playwright。真实项目导航与经过标记的合成错误响应分别记录；后者只验证界面行为，不能冒充真实运行或业务核验。完整回归与平台结果以本次交付的实测记录为准。
